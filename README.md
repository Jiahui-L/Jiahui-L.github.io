# Jiahui Liang

Personal academic homepage: https://jiahui-l.github.io/

A static academic homepage hosted with GitHub Pages. Publications can be filtered by selected papers, working papers, conferences and journals. Click an illustration to view the full figure.

## Updating the site

Edit `index.html` to update the content. Paper illustrations are stored in `assets/`; `Jiahui_Liang.jpg` is the profile photo. GitHub Pages publishes the root of the `main` branch.
